# Telegram Media Saver

Бот для Telegram: присылаешь ссылку на **Instagram**, **YouTube** или **TikTok** —
он отвечает в чат самим видео, фото или альбомом. Работает в личке и в группах.

- видео — через [yt-dlp](https://github.com/yt-dlp/yt-dlp), фото и карусели — через [gallery-dl](https://github.com/mikf/gallery-dl);
- фото и карусели Instagram качаются и без входа в аккаунт (без `cookies.txt`);
- карусели уходят одним альбомом (до 10 файлов);
- YouTube: бот сразу присылает видео в лучшем качестве до 720p, которое влезает в лимит Telegram,
  с названием ролика в подписи. Под видео — кнопки с другими качествами и их размером
  (`1080p · 45 МБ`, `360p · 12 МБ`…): нажми, и бот пришлёт тот же ролик в выбранном качестве.
  Если ролик слишком длинный для 50 МБ или что-то пошло не так — объясняет причину и даёт
  кнопку на ssyoutube.com;
- TikTok: видео, а также фото-посты (слайд-шоу) — все фото альбомом и музыка отдельным файлом,
  в том числе по коротким ссылкам `vm.tiktok.com`. Если TikTok блокирует IP сервера, бот берёт
  медиа через сторонний сервис [tikwm.com](https://www.tikwm.com) (ключ не нужен).

## 1. Создать бота

1. Напиши [@BotFather](https://t.me/BotFather) → `/newbot` → получи токен.
2. Чтобы бот видел ссылки в группах: `/setprivacy` → выбери бота → **Disable**.

## 2. Запуск локально

Нужны Python 3.11+ и ffmpeg (`brew install ffmpeg`; для YouTube ещё `brew install deno`).

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
cp .env.example .env   # впиши BOT_TOKEN
.venv/bin/python bot.py
```

## 3. Бесплатный хостинг: GitHub + Render

1. Залей эту папку в репозиторий на GitHub.
2. На [render.com](https://render.com) войди через GitHub → **New → Blueprint** → выбери репозиторий
   (настройки возьмутся из `render.yaml`).
3. Впиши `BOT_TOKEN`, когда Render спросит, и нажми **Apply**.

Дальше каждый `git push` сам выкатывает новую версию. Webhook бот ставит сам.

## Ограничения, о которых стоит знать

- **50 МБ на файл** — лимит Telegram для ботов. Длинные ролики с YouTube не пройдут.
- **Бесплатный Render засыпает** через 15 минут без запросов. Чтобы этого не было, бот раз
  в 10 минут сам обращается к своему адресу. После перезапуска или сбоя первая ссылка всё же
  может обработаться с задержкой около минуты.
- **YouTube не отдаёт видео серверам хостингов** («Sign in to confirm you're not a bot») —
  ни напрямую, ни через WARP. Поэтому, получив отказ, бот час не обращается к YouTube сам, а берёт
  ролики через открытые сторонние сервисы — ни ключей, ни входа в аккаунт, ни cookies не нужно:
  - [Invidious](https://github.com/iv-org/invidious) (`invidious.py`) — основной: знает точный список
    качеств с размерами (отсюда кнопки под видео) и справляется с длинными роликами;
  - [cobalt](https://github.com/imputnet/cobalt) (`cobalt.py`) — запасной, он же последний шанс
    для Instagram и TikTok. Кнопок с качествами после него нет.

  Серверы бот находит сам (api.invidious.io, cobalt.directory); свои можно задать переменными
  `INVIDIOUS_API` и `COBALT_API`. Их держат добровольцы: они могут пропадать, и ссылки, которые
  ты кидаешь боту, им видны.
- **Посты Instagram из профилей 18+ и закрытых** гостю не показывают. Их бот качает со входом
  в аккаунт из `cookies.txt` на хостинге (Secret File в Render), и только когда без входа не вышло.
  При запуске в логе есть строка `instagram login: ok` — значит вход жив; `expired` — cookies
  устарели, их нужно экспортировать заново. Аккаунту нужен подтверждённый возраст 18+.
- **YouTube через Cloudflare WARP (эксперимент).** При запуске бот пробует поднять бесплатный
  туннель WARP (`warp.py`) и ходит на YouTube через него — с адреса Cloudflare, а не хостинга.
  В логах при старте будет строка `WARP is ready` или `WARP is off: причина`. Если туннель
  не поднялся или YouTube отказал и ему, бот пробует напрямую с `cookies.txt`.
- **Платный прокси как надёжный запасной путь.** Если задать переменную `PROXY_URL`
  (`http://логин:пароль@адрес:порт`, прокси с «домашними» адресами, оплата за трафик), бот идёт
  через него только тогда, когда YouTube или Instagram отказали серверу напрямую и через WARP.
- yt-dlp и gallery-dl обновляются сами при каждом запуске бота (`start.sh`) — сайты меняются
  часто. Чтобы обновить их прямо сейчас, перезапусти сервис в Render (**Manual Deploy → Restart**).
